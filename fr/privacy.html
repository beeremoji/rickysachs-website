2. Informations générales sur le traitement des données

Ce site ne collecte et ne traite des données personnelles que dans la mesure nécessaire pour fournir un site fonctionnel ainsi que ses contenus et services. Les services d’analyse (Google Analytics) ne sont utilisés qu’avec votre consentement explicite (bannière de cookies).

3. Hébergement (GitHub Pages)

Les fichiers statiques de ce site sont fournis via GitHub Pages (GitHub, Inc., 88 Colin P Kelly Jr St, San Francisco, CA 94107, États-Unis). Lors de chaque visite, l’hébergeur enregistre automatiquement les données suivantes dans des fichiers journaux du serveur :

  • adresse IP de l’ordinateur à l’origine de la requête
  • date et heure de la requête
  • URL de référence (referrer)
  • nom et URL du fichier consulté
  • navigateur et système d’exploitation utilisés

Ces données ne peuvent pas être attribuées à des personnes déterminées et ne sont pas croisées avec d’autres sources de données. Base juridique : art. 6, par. 1, point f) du RGPD (intérêt légitime à la mise à disposition technique du site). GitHub est certifié dans le cadre du EU-US Data Privacy Framework. Informations sur la protection des données : GitHub Privacy Statement.

4. Formulaire de booking (Vercel + HubSpot)

Le formulaire de demande de booking transmet les données saisies via une connexion HTTPS chiffrée à une fonction serverless exploitée sur l’infrastructure de Vercel (Vercel Inc., 340 S Lemon Ave #4133, Walnut, CA 91789, États-Unis). Cette fonction enregistre ensuite automatiquement les données dans le CRM HubSpot.

Les données suivantes sont traitées :

  • nom (obligatoire)
  • adresse e-mail (obligatoire)
  • numéro de téléphone (facultatif)
  • type d’événement, date, lieu/salle, nombre d’invités, sonorisation (PA), intérieur/extérieur
  • message libre (facultatif)

Traitement par Vercel : les données ne sont traitées que brièvement afin d’être transmises à HubSpot et ne sont pas stockées durablement sur l’infrastructure de Vercel. Vercel propose un traitement des données conforme au RGPD ; le transfert vers les États-Unis repose sur les clauses contractuelles types de la Commission européenne (art. 46, par. 2, point c) du RGPD). Informations sur la protection des données : vercel.com/legal/privacy-policy.

Traitement par HubSpot : les données de booking sont enregistrées comme contact et demande dans le CRM HubSpot et utilisées pour traiter et suivre la demande. Fournisseur : HubSpot Ireland Limited, 2nd Floor 30 North Wall Quay, Dublin 1, Irlande. Le compte HubSpot utilisé est hébergé sur des serveurs situés dans l’UE. Informations sur la protection des données : legal.hubspot.com/privacy-policy.

Base juridique : art. 6, par. 1, point b) du RGPD (mesures précontractuelles prises à la demande de la personne concernée). Les données sont utilisées exclusivement pour traiter la demande de booking. Vous pouvez également me contacter directement par e-mail : booking@rickysachs.com

4a. Protection anti-spam (Cloudflare Turnstile)

Pour protéger les formulaires (newsletter, demande de booking) contre les envois automatisés (« bots »), le service Cloudflare Turnstile (Cloudflare, Inc., États-Unis) est utilisé. Le script n’est chargé que lorsque vous cliquez dans un formulaire de ce site ou y saisissez quelque chose. Des données techniques de votre navigateur ainsi que votre adresse IP sont alors transmises à Cloudflare afin de vérifier que la saisie provient d’un être humain. Aucune énigme ni image n’est affichée si la vérification en arrière-plan réussit.

Base juridique : art. 6, par. 1, point f) du RGPD (intérêt légitime à la sécurité des formulaires et à la prévention des abus) ainsi que § 25, al. 2, n° 2 TDDDG. Cloudflare est certifié dans le cadre du EU-US Data Privacy Framework. Informations sur la protection des données : cloudflare.com/privacypolicy.

Lorsque vous envoyez une demande de booking, celle-ci est également transmise par e-mail à l’exploitant de ce site. Le service Resend (Resend, Inc., États-Unis) est utilisé pour cet envoi. Base juridique : art. 6, par. 1, point b) du RGPD (traitement de votre demande). Le transfert vers les États-Unis repose sur les clauses contractuelles types de la Commission européenne (art. 46, par. 2, point c) du RGPD). Informations sur la protection des données : resend.com/legal/privacy-policy.

Base juridique : art. 6, par. 1, point a) du RGPD en liaison avec le § 25, al. 1 TDDDG (consentement). Vous pouvez retirer votre consentement à tout moment avec effet pour l’avenir, via le lien « Paramètres des cookies » en bas de chaque page ou ici :
